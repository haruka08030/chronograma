## 中優先度（プロダクト差・保守）

| 領域                     | 内容                                                                                                                                                             | メモ                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 同期モデル               | **三方向マージ**（`syncMerge.ts`）でタスク単位に `updatedAt` の新しい方を採用。同じタスクを両端末で同時に編集するとフィールド単位ではなく後勝ち。**2 端末での実機確認が未実施** | Supabase Realtime で即時反映（今はフォーカス復帰・60 秒ごと） |
| ドキュメント             | スキーマの正本は **`001_chronograma_schema.sql`**。短い説明は **`supabase/migrations/README.md`**。ルート `README.md` と `doc/CURSOR_CONTEXT.md` と同期          |                                                            |

| スマホ UX              | PWA 化・下部ナビ「今日」・計画画面の切り替えまで対応。**実機（iPhone / Android）での操作感は未確認**（タイムラインのタッチ操作、キーボード表示時のレイアウト） | 実機で確認して直す |
| Google Calendar 書き込み | 今は読み取りのみ（`calendar.readonly`）。書き込みは `calendar.events`（要 Google 審査・既存ユーザーの再同意・Edge Function 追加） | 方針決め |
