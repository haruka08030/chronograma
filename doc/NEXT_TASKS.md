# Chronograma — ネクストタスク（作業候補）

実装の正はコードと [`CURSOR_CONTEXT.md`](./CURSOR_CONTEXT.md)。本ファイルは
**優先して手を付けたい改善・未整合**
を短く集約したもの。完了したら該当行を更新するか削除する。

## 最優先: 性質の違うものが 1 つの To‑Do に混ざる問題

### 何が起きているか

ユーザーが入れるものは、少なくとも次の 4 種類に分かれる。今はどれも同じ「タスク」として扱っている。

| 種類 | 例 | 本来ほしい扱い |
| --- | --- | --- |
| 締切・予定のあるタスク | 課題、ES、ゼミ資料 | 今日の計画に出す。締切を見せる。時間を確保する |
| 繰り返し | ジム、英単語 | 習慣か繰り返しタスク。毎日の一覧で何度も「未完了」にしない |
| いつかやりたい（Wish） | 人生で一度はやりたいこと、行きたい場所 | 期限なしで寝かせる。普段は見えない。気が向いたら「今日やる」に昇格 |
| チェックリスト | 買い物、持ち物 | 店で片手でさっとチェック。予定・統計・通知には関係させない |

- リスト（`TaskList`）は名前・色・順序しか持たず、種類が無い
- To‑Do の「すべて」（`getFilteredRootTasks` の `all`）、統計（`StatsView` の `countedTasks`）、週のふりかえりは全部を数える。
  買い物のチェックで完了数が水増しされ、Wish は永遠に「未完了」として残る
- 新規ユーザーは「未分類」1 つから始まるので、とりあえず全部そこに入れる

ユーザー心理として、Wish や買い物が「やるべきこと」の横に並ぶと、選択肢が多すぎて手が止まり（選択過多）、
終わらない Wish が罪悪感のもとになる。統計が買い物で膨らむと数字を信用しなくなり、ふりかえりの価値も下がる。

### やることリスト

| 優先 | やること | メモ |
| --- | --- | --- |
| P1 | **リストに種類を持たせる**: `やること` / `いつか（Wish）` / `チェックリスト（買い物など）` | `TaskList.kind`、Supabase `lists.kind`（004 マイグレーション）、同期・バックアップ（`backupFormat.ts`）・`syncMerge` に対応。既存リストは `やること` |
| P1 | **種類ごとに出す場所を分ける**: `いつか` と `チェックリスト` は 今日 / 近日中 / 期限切れ / すべて / 今日の計画 / 統計 / 週のふりかえり / 期限通知 から除外 | 判定を 1 か所（例 `isPlannableTask`）にまとめ、`mainListTasks` / `dayPlan` / `weekReview` / `StatsView` / `notifications` から使う |
| P1 | **初期リストを用意する**: 新規ユーザーに「やること」「いつか」「買い物」 | 空の「未分類」1 つより迷わない。既存ユーザーには作らない |
| P1 | **追加時に振り分けられる**: クイック追加で `@買い物 牛乳` のようにリストを指定。「今日の計画」からの追加は常に `やること` | `parseQuickAdd` にリスト指定を追加。候補はリスト名から補完 |
| P2 | **チェックリスト用の画面**: 大きいチェック、チェック済みは下へまとめて薄く、「チェック済みを消す／全部戻す（次回も使う）」 | 日付・優先度・タイマー・DnD の UI を出さない。スマホで片手操作 |
| P2 | **いつか（Wish）用の画面**: 日付・優先度を出さず、カード状に並べる。「今日やる」「予定にする」で `やること` へ昇格 | 月に 1 回「今月かなえたいことを 1 つ選ぶ」を週のふりかえりで提案（楽しみとして使い続けるきっかけ） |
| P2 | **未分類（受信箱）の整理**: 溜まったら「振り分け」（やること / いつか / 買い物 / 削除）を 1 件ずつ提示 | 何でもとりあえず入れてよい、を保ったまま散らからない |
| P2 | **繰り返し vs 習慣の整理**: ジムのようなものをタスクで作ったら「習慣にする」を提案。クイック追加で「毎日」「毎週月水」を解釈 | 今はタスクの繰り返しと習慣が別々にあり、どちらを使えばいいか分からない |
| P3 | **実際に使ってもらって確かめる**: 学生・就活生 3〜5 人に 1 週間使ってもらい、Wish・買い物をどこに入れたか、「すべて」を開いたかを聞く | 種類の名前（「いつか」「チェックリスト」）が伝わるかもここで確認 |
