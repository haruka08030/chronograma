## 最優先: 性質の違うものが 1 つの To‑Do に混ざる問題

### 何が起きているか

ユーザーが入れるものは、少なくとも次の 4 種類に分かれる。今はどれも同じ「タスク」として扱っている。

| 種類 | 例 | 本来ほしい扱い |
| --- | --- | --- |
| 締切・予定のあるタスク | 課題、ES、ゼミ資料 | 今日の計画に出す。締切を見せる。時間を確保する |
| 繰り返し | ジム、英単語 | 習慣か繰り返しタスク。毎日の一覧で何度も「未完了」にしない |
| いつかやりたい（Wish） | 人生で一度はやりたいこと、行きたい場所 | 期限なしで寝かせる。普段は見えない。気が向いたら「今日やる」に昇格 |
| チェックリスト | 買い物、持ち物 | 店で片手でさっとチェック。予定・統計・通知には関係させない |

- リスト（`TaskList`）は名前・色・順序しか持たず、種類が無い
- To‑Do の「すべて」（`getFilteredRootTasks` の `all`）、統計（`StatsView` の `countedTasks`）、週のふりかえりは全部を数える。
  買い物のチェックで完了数が水増しされ、Wish は永遠に「未完了」として残る
- 新規ユーザーは「未分類」1 つから始まるので、とりあえず全部そこに入れる

ユーザー心理として、Wish や買い物が「やるべきこと」の横に並ぶと、選択肢が多すぎて手が止まり（選択過多）、
終わらない Wish が罪悪感のもとになる。統計が買い物で膨らむと数字を信用しなくなり、ふりかえりの価値も下がる。

### やることリスト

P1（リストの種類 `tasks` / `someday` / `checklist`、期限系ビュー・今日の計画・統計・週のふりかえり・期限通知・夕方の通知からの除外、
新規ユーザーの「いつか」「買い物」、クイック追加の `@リスト名`）は実装済み。Supabase で `004_list_kind.sql` の実行が必要。
P2 のうち **チェックリスト画面**（`ChecklistView`: 大きいチェック・チェック済みは下・「全部戻す」「チェック済みを消す」、日付 UI なし、
カレンダー・日パネル・予定 vs ログからも除外）と **いつか画面**（`SomedayView`: カード表示・「今日やる」で未分類へ移して今日の予定に・
「かなえたこと」）も実装済み。「今月かなえたいことを 1 つ」の提案は未実装。

| 優先 | やること | メモ |
| --- | --- | --- |
| P2 | **未分類（受信箱）の整理**: 溜まったら「振り分け」（やること / いつか / 買い物 / 削除）を 1 件ずつ提示 | 何でもとりあえず入れてよい、を保ったまま散らからない |
| P2 | **繰り返し vs 習慣の整理**: ジムのようなものをタスクで作ったら「習慣にする」を提案。クイック追加で「毎日」「毎週月水」を解釈 | 今はタスクの繰り返しと習慣が別々にあり、どちらを使えばいいか分からない |

## 公開前の点検（2026-10-02 追加）

### 🟠 公開前に直したい

| やること | メモ |
| --- | --- |
| **複数タブ・PWA とブラウザの同時使用** | 片方のタブで作ったタスクを、もう片方が削除してしまう。タブ間で同期を調整する仕組みが無い |
| **バックアップの読み込み** | 取り込んだデータが次の同期で元に戻る（リストの `updatedAt` が 0 になるため） |
| **localStorage が一杯になったとき** | 何も知らせずに、以降の変更が保存されなくなる |
| **1 行でも DB に拒否されると同期全体が止まる** | ユーザーに見えるのは小さなドットだけ |
| **ErrorBoundary が無い** | 描画中にエラーが起きると画面が真っ白。エラー監視の仕組みも無い |
| ~~Google の予定を Delete キーで消すと即削除~~ | 確認を出すようにした（[UI_CONSISTENCY](./UI_CONSISTENCY.md) 1-A） |
| **ログアウトすると全端末の Google 連携が切れる** | |
| **デプロイ後も古いバージョンのまま動き続ける** | Service Worker に更新の通知が無い |
| **README の手順が足りない** | 必須の 008 と 007 / 009 / 010 が抜けている。Notion の deploy 手順も無い |
| **Notion: 完了後 5 秒以内にタブを閉じると** | Notion 側のステータスが進まない |

### 🟢 余裕があれば

- JS が 1 MB の 1 ファイル。重い画面を分割して後から読み込む
- `index.html` で使っていない Google GSI スクリプトを読み込んでいるので外す
- `<html lang>` が `ja` 固定。表示言語に合わせて切り替える
- `package.json` の `version` が `0.0.0` のまま
- 初めて使う人向けの案内が無い
- push 購読の `endpoint` に入れられる URL を制限していない
- CORS がどこからでも許可（`*`）になっている
