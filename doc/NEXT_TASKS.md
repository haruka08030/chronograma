## 中優先度（プロダクト差・保守）

| 領域                 | 内容                                                                                                                                                                                                 | メモ |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| モバイル **リスト CRUD** | 現状は **pull したリストの絞り込みのみ**。端末から **リスト新規作成・リネーム・削除**が無い（Web のみで増やす前提）。削除は DB の `ON DELETE` / タスク整合に注意 |      |
| モバイル **繰り返し**    | `recurrence` は JSON で同期されるが、**完了時に次回タスクを生成する**等 Web `taskStore.toggleTask` 相当の挙動がモバイル未実装の可能性 | 仕様合わせ or モバイルでは繰り返し編集を読み取り専用と明記 |
| 同期モデル           | **スナップショット型 push**（LWW）のため、オフライン二端末同時編集では黙って上書きされうる。**衝突検知・マージ UI は無い** | プロダクト文書に一言足すか、将来の改善候補として Issue 化 |
| Web / モバイル機能差 | **クイック追加の自然言語**（Web の `parseQuickAdd` 相当）をモバイルでどこまで寄せるか方針決め                                                                                                       |      |
| ドキュメント         | スキーマの正本は **`001_chronograma_schema.sql`**。短い説明は **`supabase/migrations/README.md`**。ルート `README.md` と `doc/CURSOR_CONTEXT.md` と同期                                                                   |      |
