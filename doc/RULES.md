# Chronograma の決まり

原則は [[chronograma-ux-principles]]（記録が主役 / 締切は焦らせてよい / ごちゃつかせない /
性質の違うものを混ぜない / Google カレンダー準拠 / 想定ユーザーは学生・就活生 / PC 優先 + PWA）。

実装で守り続ける決まり。作業は GitHub の Issue、アイデアと方向性は [`IDEAS.md`](./IDEAS.md)。

## デプロイ

スキーマや Edge Function を変えたら、ターミナルで `supabase db push --linked` と `supabase functions deploy <名前>`（SQL Editor ではなく）。適用済みかは `supabase migration list --linked` で分かる。

スキーマは `supabase/migrations/` の番号順のファイル、一覧は `supabase/migrations/README.md`。ルート `README.md` と `doc/CURSOR_CONTEXT.md` もこれに合わせる。

## 通知

通知は「放っておくと逃すこと × 今なら手を打てる」ときだけ。1 日 3〜6 回が目安。

- 朝のまとめ: 今日の予定の数・今日の締切・期限切れを 1 通
- 予定の前: 開始 ◯ 分前
- 締切の前: 前日 20:00、時刻つきは当日 3 時間前
- 予定のあと: 終わりに「予定どおり / 記録する」（設定でオフにできる）
- タイマーの止め忘れ: 3 時間を超えたら
- タスク・予定ごとの通知（開始 ◯ 分前・締切の ◯ 前）を決めたら、既定の代わりにそれを使う
- 夕方の締めは無い

## 操作

- 削除は確認なしで消し、「「名前」を削除しました · 元に戻す」を出す（タスク・セクション・記録・習慣・リスト・ラベル・Google の予定）。Google の予定はトーストが消えるまで Google への削除を待つ（タブを閉じるときは待たずに送る）
- 確認を出すのは戻せないものだけ: ゴミ箱を空にする・完全に削除・アカウント削除・連携の解除
- 結果は画面下の通知（戻せるものは「元に戻す」付き、`src/lib/notify.ts`）。入力の誤りは赤字＋押せないボタン。`alert` は使わない
- 名前の変更: PC はダブルクリックかホバーで出る鉛筆、スマホは鉛筆（リスト・セクション共通）
- Enter の判定は `isSubmitEnter`。ダイアログ内の入力欄でも、欄が使わない Esc でダイアログを閉じる
- タスクの追加欄は追加後も開いたまま続けて書ける（空の Enter・Esc・外を押すと閉じる）。入れ物（リスト・セクション）を作る欄は 1 つで閉じる。表記は「タスクを追加」
- 「＋ セクション」は名前の入力から始め、名前なしで離れたら作らない。タスクも名前なしで離れたら消す（ゴミ箱・取り消し履歴に残さない）
- タスク詳細のタグ・サブタスクは、確定せずに外を押しても追加する
- 日付の入力はすべて `DateField`（期限と同じカレンダー、画面に固定して出す）。ブラウザ標準の日付欄は使わない
- 記録の保存ボタンは「記録する」（完了も兼ねるなら「記録して完了」）

## ラベルと色

- ラベル＝色に付けた名前。To‑Do と記録で共通。空は「ラベルなし」（To‑Do のタグの空は「タグなし」）
- 編集は「ラベルを編集」（✎ と同じ画面）だけ。設定は使用時間・並べ替え・その画面を開くボタンだけ
- To‑Do から記録を作るとき、分類は To‑Do のラベルから取る。名前の無い色も色のまま引き継ぐ
- To‑Do ナビの「ラベル」欄: タスクに付けた色ごとにラベル名（無ければ Google の色名）と未完了数。押すと「すべて」をその色で絞る。リストの色のままのタスクは出さない（`src/lib/todoColorLabels.ts`）
- ラベルの色を変えたら、その色の予定・タスクも新しい色へ
- To‑Do のタグは設定「To‑Do でタグを使う」（既定オフ）で出す
- 色の丸は `ui/ColorSwatches`（24 色・選択はチェック）。ナビのリストの色は 6 列、他は 12 列。自由な色の画面（`SelectColorDialog`）は別

## タイムゾーン

- アプリのタイムゾーンは設定「日付と時刻」（既定は端末）。「今」「今日」・Google の予定・止め忘れタイマー・Web Push がそれに従う（`src/lib/timeZone.ts` の `zonedNow()` / `isAppToday()`）
- タスク・記録ごとのタイムゾーンを持てる（`src/lib/taskTimeZone.ts`）。列はアプリのタイムゾーンで持ち、`timeZoneAnchor` で同じ瞬間へ書き直す
- アプリのタイムゾーンを変えると、時刻のある予定・記録は同じ瞬間のままずれる（東京 19 時 → NY 6 時）。日付だけのタスクと習慣は動かない。書いたタイムゾーンが分からない古いものは、最初に開いたときのタイムゾーンで書いたとみなす
- タイムラインの時間バーに他のタイムゾーンを 2 つまで並べられる（`TimeGutter.tsx`）

## 表示

- 1 日の区切りは朝 4 時（`DAY_START_HOUR`）。夜中の 0〜4 時は前の日を「今日」とし、今日の計画・To‑Do の今日/期限・習慣・統計・クイック追加の「明日」がそれに従う。現在の線と「過ぎた予定」は実際の時刻のまま。夜中に前の日を開くとタイムラインは夕方から
- 一括選択のチェックはホバーで出す。タッチでは行の長押しで選択に入れるので、iPad でも常時は出さない（全行にチェックが並ぶとごちゃつく）
- 常時出す説明文は置かない。残すのは iPhone/ブラウザの追加手順、アカウント削除の警告、追加欄の例（入力中だけ）、エラー・確認、ホバーのツールチップ
- 期限切れは今日のリストの先頭に赤い日付つきで出す（`getDayPlan().overdue`）
- 「計画どおり実行」は終わった時間帯の予定だけで数える
- 統計の日別の棒は分類の色で積む。内訳は「タグ別」
- 習慣は「週に3日」ではなく曜日（月・水・金）で出す
- Google カレンダーの接続中は日付の隣の緑の点だけ（乗せる・タップで「Google Calendar 接続中」）。エラー時だけ赤い 1 行＋切断。接続・切断は `src/hooks/useGoogleConnect.ts`
- カレンダーの「時間未定のタスク」は押し込み表示（`aria-pressed`）
- カレンダーのタスクはどこでもその場で ✓（`timeline/CalendarCheck`）: 月のマス・終日の行はチップの左、時間ブロックは右上。完了済みは塗りの ✓ で、押すと戻せる。時刻のあるタスクは To‑Do の一覧と同じく「完了を記録」を出す（`useCompleteWithLog`。日のパネル・時間未定のタスクも同じ）

## 同期・保存

- 他タブの保存は storage イベントで取り込み（表示中の画面はタブごと）、同期は Web Locks でタブ間 1 本ずつ
- 送るのは取得した内容と違う行だけ。削除 100 件・保存 500 件ずつ
- localStorage が一杯なら取り込みの控えを手放して再試行、だめなら書き出しボタン付きのバナー
- ログアウトは先に送ってから。失敗時だけ確認。サーバーで切れなければ端末のセッションだけ消す
- バックアップの取り込みは全項目を検査・補完し、今編集したものとして刻む
- 保存データが読めないときは別キーに退避し、エラー画面に「書き出す」「自動バックアップから戻す」
- 繰り返しタスクの次回の id は「元の id@期限」
- Canvas の接続は 1 人 5 校まで
- DB の行には大きさの上限（タイトル 2000 字・メモ 20 万字・名前 500 字など、`005_size_limits.sql` の `*_size_check`）。送る前に同じ長さで切る（超えると同期が止まり続けるため）
- ログインせずに使っていた端末の初回同期: 中身の無い「いつか」「買い物」はアカウントに同じものがあれば外す。手元にサーバーに無いリスト・セクションがあれば合わせて残す
- 持ち主の記録が無い古いデータ（`*legacy*`）は、その人として同期した控えがあればその人のもの。ほかの人の控えしか無ければ外す
- 通知の「予定どおり」で開いた URL だけ確かめずに記録する（Cache Storage の 1 回きりの印）。印の無いリンクは記録の画面を開くだけ
- 新しい版は戻ったときに確認し、切り替わったら画面が隠れたときに再読み込み。デプロイ直後の古いタブは 1 回だけ再読み込み
